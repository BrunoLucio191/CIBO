## Política

Pesquisar primeiro na biblioteca aprovada do cliente. Validar a licença do item individual, salvar autor/fonte/URL/licença/data/hash e não presumir que “gratuito” significa domínio público. Vídeo stock fica local no projeto e nunca sobe para o Drive de skills/assets.

## Vídeo stock e B-roll

| Fonte | Automação | Melhor uso | Licença/atribuição | Observações |
|---|---|---|---|---|
| Pexels | API oficial | pessoas, negócios, ambiente, ações reais | licença do item | sem watermark; stock local only |
| Pixabay Video | API oficial | partículas, fundos, animações e cenas | licença do item | stock local only |
| Coverr | API/MCP | planos cinematográficos | termos atuais; atribuição pode ser exigida | não treinar IA; stock local only |
| Mixkit Video | manual | transições e atmosfera | item Free License | não raspar |
| Wikimedia Commons | API | histórico/documental | variável | conferir item |

## Música

| Fonte | Automação | Regra principal |
|---|---|---|
| Openverse | API | priorizar CC0/PD; CC BY com crédito; rejeitar BY-NC |
| Coverr Music | API/MCP | verificar atribuição; não redistribuir/treinar |
| Wikimedia Commons | API | direitos da composição e gravação separados |
| Internet Archive | API | aceitar apenas `licenseurl` explícita |
| Pixabay Music | manual | guardar comprovante e risco de Content ID |
| Mixkit Music | manual | Free License; não redistribuir isoladamente |
| YouTube Audio Library | manual | sem scraping; licença por faixa/destino |
| Incompetech | manual | normalmente CC BY 4.0 com crédito completo |

## SFX

- Freesound API: CC0 automático; CC BY somente com créditos; rejeitar CC BY-NC.
- Preferir SFX próprios/sintetizados e biblioteca local aprovada.

## VFX, FSX, overlays e transições

- Pexels, Pixabay e Coverr por API/licença individual.
- Mixkit manual; ProductionCrate/Videvo apenas com licença confirmada e download autorizado.
- Priorizar alpha real (ProRes 4444, PNG sequence, WebM alpha). Fundo preto usa Screen/Add; branco usa Multiply; chroma verde é último recurso.
- Subir ao Drive quando reutilizável e permitido, com preview, manifesto e comprovante. Se a licença proibir re-hospedagem, subir somente referência/metadados.
