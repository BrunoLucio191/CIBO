# Métricas e fórmulas

Sempre informe a fórmula usada ao lado da taxa no anexo. Arredonde taxas a 1 casa (%).

## Regras de comparação
- Compare cada plataforma com ela mesma (mês vs. anterior, post vs. média da conta).
- Entre plataformas, só taxas — nunca views/alcance brutos.
- Instagram: alcance da conta (Resultados) ≠ soma do alcance dos posts. Para a conta, use o print.
- Média da conta = mediana por post quando houver outlier (diga qual usou).

## Taxas por post
| Taxa | Fórmula | Observação |
|---|---|---|
| Engajamento por alcance (IG) | (curtidas + comentários + salvamentos + compartilhamentos) / alcance | por post |
| Engajamento por view (TikTok/YT/Reels) | (curtidas + comentários + compartilhamentos + salvamentos) / views | views não equivalem entre plataformas |
| Salvamentos / alcance | salvamentos / alcance | sinal de conteúdo de valor (meio de funil) |
| Compartilhamentos / alcance | compartilhamentos / alcance | sinal de descoberta (topo) |
| Seguidores por 1.000 views | seguidores ganhos / views × 1000 | conversão de descoberta em audiência |
| Retenção | tempo médio assistido / duração; % que assistiu inteiro | TikTok/YouTube/Reels quando houver |
| CTR de thumbnail (YT) | do YouTube Studio | só YouTube |

## Funil (passagens)
- Alcance/views → visitas ao perfil: visitas / alcance da conta
- Visitas ao perfil → seguidores: novos seguidores / visitas
- Visitas ao perfil → cliques no link: toques no link / visitas
- Cliques → leads/vendas: se o cliente fornecer (senão, lacuna declarada)

## Amostra
- Padrão consistente: ≥3 posts, em ≥2 semanas diferentes, acima da mediana.
- Caso isolado: 1–2 posts; pode virar teste, não regra.
